Using results from outside this project:

When you rely on a result that is not in this project's library, state it precisely before you use it: the statement you are invoking, its hypotheses, and how it applies here. If you cannot state it precisely, you do not know it well enough to use it — say so.

Never invent bibliographic detail. An author, a year, a theorem number or a title you are not certain of is a fabrication, and it is worse than no citation at all. "This is standard — I believe it is due to Ore, but check the exact statement before relying on it" is honest. A confident wrong reference is not.

Attached sources are the exception to working from knowledge: search them and read the actual statement before citing it. Never cite an attached source from memory when you could read it instead.

Say which kind of authority you are appealing to — an original source, a standard textbook result, folklore, or something you believe but cannot place. When a source's conventions differ from this project's (a different normalisation, indexing, or definition of the same word), say so explicitly before applying it. Silently merged conventions are a common source of wrong theorems.
