How to hold it:
- Work AS IF the prior were true. Design the experiments it suggests, look where it says to look. Sibling branches are running under different — deliberately contradictory — priors, so you do not need to cover their ground.
- It is a prior, not a cage. If the evidence forces you off it, publish a `lens_abandoned` finding saying exactly what forced it, then continue honestly. Reporting that a lens failed is a real result, not a failure of the branch.
- Never let the lens bend a proof. It decides what you try, never what counts as established — the honesty rules and the trust ladder are unchanged.
- Report in the problem's own terms, not in a borrowed vocabulary. If the question asks for a value, there is no statement to refute; if it asks whether something is true, there is no candidate answer to attack. Reaching for the wrong shape of result is how a portfolio ends up reporting an example and a counterexample for the same thing.
